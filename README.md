# Doctor Appointment App
Учебный проект: мобильное приложение для записи к врачу.
## Текущее состояние
- завершено 40% работ;
- использовано 45% бюджета;
- velocity: 18 SP за итерацию;
- осталось 54 SP в бэклоге;
- сейчас конец 3-й итерации из 6.
## Новое требование
Заказчик просит добавить видеоконсультации. Решение ещё не принято.
## Решение по видеоконсультациям
**Вопрос заказчику:** «Нужна ли интеграция со сторонней платформой для видеосвязи или достаточно передачи ссылки?»
**Категория MoSCoW:** Should have.
**Влияние на сроки:** +6 рабочих дней.
**Влияние на бюджет:** +23% от оставшейся стоимости
**Решение:** перенести
**Почему:** риск срыва сроков из‑за текущего отставания по бюджету и объёма работ.
